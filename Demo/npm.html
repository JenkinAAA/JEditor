AI Prompt Keywords For Static Fragment HTML

Prompt Tips

如果你要让 AI 生成一个可以直接贴进 JEditor 或第三方系统的静态 fragment HTML，建议提示词里至少包含这些关键词：

  • self-contained fragment html
  • inline styles only
  • email-safe layout
  • no external scripts
  • max-width container
  • semantic headings and tables
  • callout card section
  • code block with language label
  • copy-paste friendly output
